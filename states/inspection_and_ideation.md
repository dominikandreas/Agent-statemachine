# inspection_and_ideation

Inspect current behavior and surface the next valuable improvement idea.

## Intent
- study the current system or repo when the next move is not ready yet
- identify one concrete problem worth acting on next
- generate bounded ideas instead of blind patches

## Allowed
- inspect metrics, traces, artifacts, diffs, or failing tests
- compare current behavior with goal behavior
- rank the next target
- write a short ideation note or task entry

## Not allowed
- endless diagnostics with no narrowing
- disguised implementation

## Required output
- one concrete problem or gap
- one target area, metric, or symptom
- 1-3 plausible next ideas
- one prioritized next step

## Typical next states
- `planning`
- `refactoring`
- `implementation`
